# 🏥 MediFlow AI

> Autonomous Multi-Agent Healthcare Coordination Platform

MediFlow AI is an AI-powered healthcare coordination platform that bridges the gap between patients and healthcare providers. Using multiple autonomous AI agents, the system streamlines symptom intake, specialist recommendation, appointment management, and prescription understanding.

---

## 🚀 Features

### 👨‍⚕️ Patient Portal
- AI-powered symptom intake assistant
- Dynamic symptom analysis through natural conversation
- Automated specialist recommendations
- Appointment booking and tracking
- Prescription management dashboard
- AI-generated medication explanations
- Medication follow-up chatbot

### 🩺 Doctor Portal
- Appointment queue management
- AI-generated patient intake summaries
- Consultation workflow support
- Prescription creation and management
- Automated prescription explanation generation
- Patient history and treatment tracking

### 🤖 AI Agents

#### 1. Symptom Analysis Agent
- Collects symptom details through conversation
- Determines symptom severity and duration
- Generates structured patient summaries

#### 2. Specialist Routing Agent
- Analyzes patient symptoms
- Recommends the most appropriate specialty
- Matches patients with doctors

#### 3. Appointment Scheduling Agent
- Coordinates appointments
- Manages consultation workflows

#### 4. Prescription Explanation Agent
- Converts prescriptions into patient-friendly language
- Explains dosage instructions
- Highlights precautions and side effects
- Generates medication FAQs

#### 5. Follow-Up Assistant Agent
- Answers medication-related questions
- Provides treatment guidance
- Supports medication adherence

## 🔑 Gemini API Setup

1. Obtain a Gemini API Key from Google AI Studio.
2. Open the application.
3. Click the **API Key** button in the navigation bar.
4. Enter your Gemini API key.
5. The key will be stored locally in your browser.

## 📦 Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/mediflow-ai.git
cd mediflow-ai
```

### Run Locally

Simply open:

```bash
index.html
```

Or start a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
